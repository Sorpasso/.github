## What we build

Sorpasso is a Formula 1 data and analytics platform, currently in active development. It brings 75+ years of race history and live session data into one fast desktop app.

- **Historical archive:** every season, driver, constructor and circuit since 1950
- **Live weekend view:** session schedules, results, weather and team radio
- **Analysis:** season progression, constructor dominance, pit stops, reliability and teammate head-to-heads
- **Records and eras:** curated all-time records, regulation eras and rule changes
- **News:** aggregated F1 headlines, auto-categorised

## Principles

- **Native and fast.** Rust backend, cached on disk, usable offline for historical data.
- **Private.** No tracking, no telemetry, no sign-in.
- **Respectful of upstream.** Rate limiting, backoff and caching on every request.

## Platforms

macOS, Windows and Linux.

## Status

Sorpasso is a commercial, closed-source product in active development. There is no public release yet, and we are not accepting contributions at this time.
